# Pack_PLugins_Super_Productivity

Pacote de plugins e extensões para o Super Productivity e MCP (Model Context Protocol).

## Conteúdo do Repositório

### 1. Vision Board Plugin (`vision-board-super-productivity`)
- Quadro visual customizável estilo canvas para Super Productivity.
- Suporte a cards com imagens, notas em Markdown com formatação rica, metas com contagem regressiva circular em tempo real e linhas de conexão.
- Guias inteligentes de alinhamento magnético (smart snapping guides).
- Persistência contínua do último nível de zoom e da última posição (pan/scroll) no canvas.
- Arquivo pronto para instalação: `vision-board-super-productivity.zip`.

### 2. Meal Tracker Plugin (`meal-tracker-plugin`)
- Plugin de acompanhamento diário de refeições e nutrição para Super Productivity.
- Registro de calorias, macronutrientes e metas diárias.
- Arquivo pronto para instalação: `meal-tracker-plugin.zip`.

### 3. Letterboxd MCP Server (`letterboxd-mcp`)
- Servidor MCP para integração e consulta de dados e listas do Letterboxd.
- Configuração Node.js com cache e resolução de títulos.

## Como Instalar os Plugins no Super Productivity
1. Abra o Super Productivity.
2. Vá em **Configurações** > **Plugins**.
3. Clique em carregar plugin e selecione o arquivo `.zip` desejado (`vision-board-super-productivity.zip` ou `meal-tracker-plugin.zip`) ou aponte para a pasta descompactada.
